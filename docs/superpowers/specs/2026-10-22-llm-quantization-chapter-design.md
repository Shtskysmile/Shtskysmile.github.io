# LLM 量化章节设计

## 意图与目标

为《大语言模型面试复习：基础知识与后训练专题》补上系统的模型量化知识，帮助读者理解低比特量化如何影响模型精度、显存、吞吐与部署选择。保持现有中文面试复习风格，提供可用于面试回答的概念框架和工程判断。

## 非目标

- 不编造特定模型、硬件或量化方法的固定性能数字；效果依赖模型、数据、实现和硬件，应强调实测。
- 不展开成量化算法论文综述，也不重复已有的 QLoRA、KV Cache 和蒸馏内容。

## 约束

- 内容直接加入 `content/blog/llm-interview-review.md`，沿用现有章节标题、公式、表格和面试要点格式。
- 以模型权重量化和推理部署为主；关联说明 KV Cache 量化。
- 插入为独立章节，后续章节编号顺延；同步修正正文内指向这些章节的编号引用（如有）。

## 方案与取舍

- 独立章节：结构完整，便于复习和链接定位；后文编号需要顺延。**选用此方案。**
- 并入第十九章的训练系统：编号改动较少，但量化会被埋在系统话题中，缺少清晰的复习入口。

## 章节内容

新增“模型量化：低比特推理与部署”章节，覆盖量化对象与精度/显存直觉、PTQ 与 QAT、权重量化和权重/激活量化、代表性方法（如 GPTQ、AWQ、SmoothQuant、bitsandbytes 的常见路径）、精度和系统指标评估、校准与部署中的常见陷阱、方法选型，以及面试要点。用必要公式或小表格解释取舍，不承诺跨场景通用的性能倍数。
