## 基础

**1. [面/笔] 冯·诺依曼结构的核心思想是什么？**

核心是「存储程序」思想，即指令和数据都存放在统一存储器中，CPU 按顺序取指、译码、执行。这让通用计算机能够通过修改程序而不是硬件来完成不同任务。

**2. [面/笔] 计算机中为什么要有多级存储结构？**

因为速度快的存储器通常更贵、更小，容量大的存储器通常更慢。多级存储就是在速度、容量和成本之间折中，用少量高速存储弥补主存和外存的慢。

**3. [面/笔] Cache 的作用是什么？什么是局部性原理？**

Cache 用来缓存最近或附近会再次访问的数据，从而降低平均访存时间。局部性原理包括时间局部性和空间局部性，是 Cache 能有效工作的理论基础。

**4. [面/笔] 什么是中断？什么是异常？二者有什么区别？**

中断通常来自外部设备，如 I/O 完成；异常通常来自当前指令执行过程，如除零、缺页。二者都会打断当前执行流交给内核处理，但来源不同。

**5. [面/笔] 定点数和浮点数有什么区别？**

定点数小数点位置固定，实现简单但表示范围有限；浮点数用尾数和指数表示，范围更大，适合科学计算，但会带来舍入误差。

**6. [面/笔] 什么是指令周期？**

指令周期是 CPU 完成一条指令所经历的完整过程，通常包括取指、译码、执行以及可能的访存和写回阶段。

**7. [面/笔] 大端和小端分别是什么？**

大端把高位字节放在低地址，小端把低位字节放在低地址。它们影响多字节数据在内存中的存放方式，网络字节序通常采用大端。

## 进阶

**1. [面/笔] 直接映射、组相联、全相联 Cache 的区别是什么？**

直接映射中每个主存块只能放到一个固定位置，实现简单但冲突多；全相联可放任意位置，命中率高但查找硬件复杂；组相联是折中方案，在固定组内任选位置。

**2. [面/笔] 写回和直写的区别是什么？**

直写是每次写 Cache 都同步写主存，简单但写流量大；写回是先只改 Cache，替换时再写回主存，效率高但一致性管理更复杂。

**3. [面] 流水线为什么能提升吞吐量？数据冒险、控制冒险是什么？**

流水线把一条指令分成多个阶段，让不同指令在不同阶段并行执行，因此提升吞吐量。数据冒险来自指令间数据依赖，控制冒险来自分支跳转导致后续取指不确定。

**4. [面] 为什么浮点数计算会有精度误差？**

因为浮点数只能用有限位数表示无限多的实数，很多数只能近似存储。多次运算后舍入误差会累积，所以结果可能和数学上的精确值不同。

**5. [面] CPU、GPU 分别适合什么类型的计算？**

CPU 适合控制复杂、分支多、低并发但通用性强的任务。GPU 拥有大量并行计算单元，更适合矩阵运算和大规模数据并行任务，如深度学习训练。

**6. [面] SIMD 在现代计算机中解决什么问题？**

SIMD 是「单指令多数据」，一条指令同时处理多个数据元素。它提升向量运算、图像处理和矩阵计算等场景的吞吐能力。

## 拔高

**1. [面] Attention 为什么既吃算力又吃显存？**

因为 Self-Attention 需要计算并存储 `QK^T` 形成的注意力矩阵，其规模随序列长度平方增长。序列一长，不仅乘法量大，注意力权重、中间激活和梯度也会占用大量显存。

**2. [面] KV Cache 在推理时解决了什么问题？它为什么会成为长上下文下的内存压力来源？**

KV Cache 把历史 token 的 Key 和 Value 缓存起来，生成新 token 时不用重复计算前面所有位置，因此推理更快。但上下文越长，要缓存的历史 K/V 越多，显存就会持续上涨。
