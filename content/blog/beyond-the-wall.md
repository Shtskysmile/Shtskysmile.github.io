# 跨过长城，刺穿金盾

### 一份不存在的国策树

> [!NOTE] 前置条件
> 本条国策线不对任何国家开放。它不在官方树里，不出现在加载提示里，也不能被搜索框检索到。
> 熟练度足够的人，会在别的地方见过它。

## 国策树总览

| 层级 | 情报 | 物资 | 技术路线 | 深渊 |
| :--: | :-- | :-- | :-- | :-- |
| I | 邻人皆通 | 寻找器具 | | |
| II | 墙非一堵 | 试用期已过 | | |

| IV | | 订阅续期 | 配置文件 | 沉默成本 |
| V | | | | 今日无事发生 |

树上一格都不互斥，全都能叠。所谓选择只在点与不点之间。

## 一、情报线

### 邻人皆通

**前提：** 无

**效果：** 稳定度 −5%；解锁「隔壁宿舍」决议

第一次意识到这件事，通常不是从新闻里，是从别人的笔记本上。同一个校园网，同一门课，同一个人群，有人在做什么，你只是刚好站在旁边看见了。

### 墙非一堵

**前提：** 邻人皆通

**效果：** 政治力量 +10；获得国家精神「一知半解」

后来才知道它不是一堵。有的地方形同虚设，有的地方密不透风，有的地方昨天还通今天就不通。用同一套办法应付它们，早晚会在某个角落里撞上。

> [!NOTE] 提示
> 这一格的实际效果远高于面板显示。多数人卡在「邻人皆通」就不再往下点了。

## 二、物资线

### 寻找器具

**前提：** 墙非一堵

**效果：** 解锁装备栏；每月消耗时间 +2

到这一步才开始谈工具。工具本身没有立场，它只是个能转发的管道，问题从来在管道两头。

### 试用期已过

**前提：** 寻找器具

**效果：** 稳定度 −10%；获得国家精神「时断时续」

便宜的那批通常有期限。到期那天你还开着，页面只是转圈，你以为是自己网络的问题，重启路由器，换浏览器，清缓存，最后才发现是别的地方断了。

### 自建

**前提：** 试用期已过

**效果：** 解锁「服务器」决议组；开启外交槽位

买机器，装系统，配路由，对着文档改到凌晨。这条路最贵也最稳，因为它把主动权从别人手里拿回来一部分。

### 订阅续期

**前提：** 自建

**效果：** 每月扣除开支；获得国家精神「日常开销」

最终多数人会回到按月付钱。不是自建不好，是自己维护的成本在第三个季度之后开始反超。

## 三、技术路线（可叠加）

两条路的终点一样，代价不一样。它们不互斥——多数人最后是两个都开，各管一摊。

### 系统代理

**前提：** 订阅续期

**效果：** 覆盖范围——仅认代理的应用；配置成本 低；遗留痕迹 多

**备注：** 生效范围写在系统的设置里，所有程序都看得见。有人喜欢这一点，因为好排查；也有人不喜欢，原因同样。

### 虚拟网卡（TUN 模式）

**前提：** 订阅续期

**效果：** 覆盖范围——全局；配置成本 高；遗留痕迹 少

**备注：** 从进程到流量全部接管，代价是权限、路由表和偶尔的 DNS 打架。

**叠加说明：** 两个一起开是常态，不是取舍。系统代理负责认得出代理的应用，剩下的漏网流量由 TUN 兜住。真要出问题，多半是两个都想接管同一段流量，那时候才需要挑一个关掉。

### 配置文件

**前提：** 系统代理 **和** 虚拟网卡

**效果：** 解锁决议「改规则」；触发事件「手动维护」

整个树里最需要耐心的一格。它平时安静，偶尔在某个凌晨被上游改坏，规则集指向的域名下线，分流全乱，看起来像是整条线路死了，其实只是一行没跟上。

改它的人后来都学会了在动之前先复制一份。

## 四、深渊线

这条分支不属于任何一条主线。它只在前面所有格子都点完之后才显形。

### 沉默成本

**前提：** 配置文件

**效果：** 政治力量 −20；获得国家精神「不必说」

代价不是钱，也不是时间。是发现自己已经习惯不在某些场合提起这件事，习惯在换设备时先检查一遍，习惯把某些词换一种说法。

工具没变，说话的方式变了。

### 今日无事发生

**前提：** 沉默成本

**效果：** 全部修正归零；解锁决议「继续」

树到此为止。面板上不再有任何一格可以点。

墙还在，金盾还在，你的这一份配置也还在。今天能连上，明天接着看。
