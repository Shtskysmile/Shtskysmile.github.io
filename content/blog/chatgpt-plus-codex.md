# 血肉苦弱，智械飞升（三）：购买 GPT Plus 接入 Codex

> [!NOTE] 这个系列
> 第一篇用 API 和中转站把 DeepSeek 接进 Claude Code；第二篇介绍只提供 OpenAI 协议的 Command-Code-GO，以及 CC Switch 的协议路由。
>
> 第三篇切换到官方订阅路径：使用 ChatGPT Plus 账号登录 OpenAI Codex。这里说的“满血”，指请求由 OpenAI 官方 Codex 服务处理，不经中转商替换模型；它不表示额度无限，也不保证所有模型永久对所有账号开放。

## 一、官方订阅与中转站的区别

API 中转需要把请求交给第三方网关。网关如何转发、实际使用哪个上游模型，取决于服务商的实现。模型名称写成某个品牌，不足以单独证明实际调用的模型就是该品牌的官方模型。

Codex 使用 ChatGPT 账号登录时，请求直接进入 OpenAI 的 Codex 服务，模型来源由 OpenAI 提供。这样可以避开中转服务在上游选择和模型映射环节替换模型的问题。相较于依赖第三方网关，这条路径更能保证模型来自官方。

但“官方模型”不等于“无限使用”。Codex 的模型和使用额度取决于订阅计划、任务规模以及 OpenAI 当时提供的功能和限额。Plus 的额度可能有限，复杂或持续时间较长的编程任务也会消耗更多用量；具体可用模型和额度应以账号内页面为准。

## 二、购买渠道与风险

GPT Plus 可以在 ChatGPT 账号的订阅页面查看官方升级方式。本文也列出一个第三方购买网站：<https://www.aivora.cn>。该网站目前将自己介绍为 AI 账号店，但这里没有对其商家资质、商品来源、售后或账号归属进行独立核验，因此不能把它视为 OpenAI 官方渠道，也不对交易结果作担保。下单前应自行核对商品内容、账号归属、售后条件和退款规则。

第三方渠道的关键区别在于：购买的是**给本人账号代开订阅**，还是卖家直接交付一个账号及密码。后者可能是多人共用或无法由买家控制的账号。OpenAI《使用条款》规定，用户不得分享账号凭据或将账号提供给他人使用；违反条款或被认定存在风险时，账号可能被暂停或终止。若账号因此失去访问权限，剩余订阅费用也可能难以追回。

因此，风险较低的做法是使用本人注册、本人控制邮箱和恢复方式的账号，并确认购买内容是在该账号上开通订阅。不要把本人邮箱密码、验证码、恢复码或双重验证代码交给商家。若商家只提供一个现成账号及密码，买家通常无法确认账号是否独占、能否长期控制或是否会被原持有人找回，不建议将其作为长期工作账号。

> [!NOTE] 购买前检查
> - 确认商品是给本人账号开通订阅，还是交付共享/现成账号。
> - 确认邮箱、密码、恢复方式和双重验证由谁控制。
> - 确认开通周期、续费方式、退款和售后边界。
> - 不要在有重要对话、代码或个人资料的主账号上试用来源不明的账号服务。

## 三、登录 ChatGPT 账号

优先在官方 ChatGPT 应用或 <https://chatgpt.com> 登录本人控制的账号。若购买的是本人账号上的订阅，登录时输入自己的邮箱或选择原有登录方式，再按页面提示完成密码、邮箱验证码或其他验证。

商家提供的说明书通常会写明其商品类型和交付步骤，可以用来核对购买流程；它不能替代 OpenAI 官方登录页面，也不应要求买家向商家发送本人账号的密码或验证代码。若商品交付的是独立账号，常见登录步骤是在官方 ChatGPT 或 Codex 页面选择登录，输入说明书提供的账号邮箱和密码，再按官方页面提示完成验证，最后检查个人菜单中的订阅状态。只有确认页面域名属于 OpenAI 后才输入凭据。

这种登录流程只说明如何进入账号，不代表账号归属合规或长期可用。OpenAI 条款不允许分享账号凭据；商家提供的独立账号可能由他人控制，也可能被找回或暂停。无法确认账号由本人独占时，不建议用于 Codex。

## 四、在 Codex 中登录

安装并打开官方 Codex 客户端，或在终端运行已安装的 Codex CLI：

```bash
codex
```

首次运行时，按客户端提示选择使用 ChatGPT 账号登录。浏览器会打开 OpenAI 的授权页面：检查地址属于 OpenAI 官方域名，登录本人账号，并确认授权后回到 Codex。桌面客户端与 CLI 的按钮和提示可能随版本变化，按当前官方客户端给出的流程操作即可。

成功后，Codex 应显示已连接的账号或进入可使用状态。若终端提示登录异常，先确认浏览器登录的是预期账号、订阅仍有效，并更新 Codex 客户端；不要为了排错把密码或验证码发给第三方。

OpenAI 官方说明，Codex 可通过 ChatGPT 计划使用，计划额度会因任务复杂度和执行时长而变化。登录完成后，可以在 Codex 或 ChatGPT 的使用页面查看当前额度与限制。若达到上限，应以官方页面提供的重置时间或额外用量选项为准。

## 五、这条路径适合什么情况

如果优先考虑模型来源可确认、并希望直接使用 OpenAI 官方 Codex，官方账号登录比未知中转网关更直接。它省去了 Base URL、API Key 和协议转换配置；模型是否可用则仍受账号计划和官方额度约束。

第三方购买会额外引入交易和账号控制风险。尤其是卖家直接交付账号密码的情形，账号是否独占、能否长期找回、订阅是否会被撤销都不由 Codex 登录流程保证。将订阅用于长期开发环境前，应先确认账号由本人控制，并避免在不可控账号中存放私有代码、密钥和重要对话。
