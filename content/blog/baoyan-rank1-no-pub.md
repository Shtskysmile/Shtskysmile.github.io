# 纯 rank 无 pub：电子科大计算机 1/163 的保研记

我是电子科大计算机的，rank 1/163，没有 pub。二月份的时候，名下只有一篇期刊在投。

我一直没写过保研帖，在群里聊完这一遍之后，觉得可以写了。先放结果，后面按时间顺序讲。

| 营 | 结果 |
| --- | --- |
| 北大软微 | 弱 com，老教授推荐入营，最后去的这里 |
| 中科大 AIDS | 卡 rank 1，进营，优营 |
| 人大苏州 | 优营，榜上第 3，最后没去 |
| 人大高瓴 | 专硕第 18，候补优营 |
| 清深 LLM | 强 com 入营，面试没过 |
| 上交软 | 入营，和高瓴冲突，放弃 |
| 复旦计 | 九月入营，老师口头说可以招，要先过学院考核 |
| 南大计 | 过了初赛 |
| 南大软 | 入营 |
| 浙大 AI | 没进营 |

> [!NOTE] 几个词
>
> - pub：发表的论文
> - 陶瓷：套磁，提前联系老师
> - 打工：提前进老师组里干活，换成果和署名
> - 羊导：脾气好、压力小的导师
> - 强 com、弱 com：强 com 是学院统一考核、按成绩排名；弱 com 是老师说了算，提前联系和推荐都算这一路

## 没有论文

组里的传统是投期刊，我当时没意识到，后来发现，科研这条线应该是救不回来了。

三月到六月，我一直在焦虑没有论文怎么办。心态最崩的那阵，我甚至想过干脆留本校，去找自己的本科老师读研。他说要先面试我，考核一下。我想，本校 rank 1，在他这里干了这么久，还要面试？后来另外找了一位本校老师，当场就给了 offer。

## 学长

我大创老师给我分了个工位，旁边坐着一位学长，双非本科，保研到了电子科大。我去问他：有没有必要找个老师打工，赶一篇 AAAI 去投？我自己都不指望能中。

他说没必要。

他的意思是，电子科大计算机 rank 1，进绝大部分营已经够了。我的目标是就业，找个羊导，用不着去强组卷，论文可以不要。AAAI 挂个在投，用处也不大。

他让我从三月开始一直复习：408、数学、LLM、Agent、机器学习。强 com 的面试，复习到位就能碾过去。

陶瓷可以套，打工要谨慎，我在打工上没有任何优势。陶瓷是为了面试，不是为了拿 offer。大部分老师面试问的内容差不多，面一个，复盘一个，到最后一个夏令营，我的面试一定无敌。机考也要准备。简历面试要认真对待，简历上写的每一样东西都得熟到不能再熟，不能怯场。

怯场我倒不担心。我面试不吃压力，老师给我压力，我也感觉不到，只觉得他在跟我探讨知识。

我就照着他说的做了。三月到六月，一直在复习。

## 软微

第一个营是软微，走的弱 com，这一条比较看运气。

老师是一位很特殊的老教授。他不喜欢科研多的学生，那些全被他转给了软微的另一位老师。他自己招过两个中九的 rank 1，把我保送进了营。我需要这样的老师。

软微的另一位老师我也套过，没人理我。夏令营报名前夕，倒是有不少老师向我递橄榄枝，但我不敢赌别的老师真的会要我。老教授对我的态度最好，我个人也喜欢老教授，他很可能是个羊导。

软微的优营是弱 com，老师按名额等额推荐给教务。面试我自己感觉发挥得也很好，就算不靠他保送，我应该也能过。

## 中科大 AIDS

第二个营是中科大的人工智能与数据科学学院，简称 AIDS。AIDS 筛选时卡 rank 1，我进了。

机考全是 LeetCode Hot 100 的原题，三十分钟写完，睡大觉了。

面试之前我有点担心：没有论文，会不会吃瘪？上台以后，我把自己做的所有工作明明白白讲给老师听。老师问的每一个问题，我的论文里都涉及过，答得很顺。最难的是英语，他让我用英文解释一下图对比学习（推荐系统里的那种，不是 CLIP）。我六级不高，但一直有练口语，敢说，基本完整地用英文讲了一遍。

进了营以后，rank 不再起作用，我发现论文也差不多。老师更在意你能不能讲清楚，有条有理地把一件事讲完整，比中没中稿更重要。我那篇论文是自己手搓出来的，那时候 AI 还没这么发达，每一个细节我都熟。

AIDS 最后给了优营。双选我懒得做，优营名单出来过了十八个小时，我才去问意向的老师想不想要我，老师说没名额了。我也懒得再争，双选就放弃了。我已经有软微了，来这干啥。

## 人大苏州

第三个营是人大苏州，简称人苏。

先是群面，我每一轮都抢着第一个发言。自信就完事了，怕个蛋。

专业面是抽题，我抽到的是解释 RLHF。学长让我多看看 LLM 和 Agent，这里用上了。Agent 不算专业课，但很重要。这一关当场就过了。

简历面问到的东西，基本都是我之前面试里讲过的。我在这一场做的最重要的工作，是骗他们我没有软微的 offer，我一定来，一定来。

第二天笔试：五道 LeetCode Hot 100，手撕；一道英语翻译，手撕；还有一道思政，问中国式现代化的五个方面，我想起来四个。我记性好，这一道可能不算分。

人苏是我所有优营里排名最高的一个，3/100+。入营的有一百多人，人大筛掉一部分，榜上好像剩五十六个，我排第三。人苏最后只招七个人，人大历来是先判合格，再按招生人数录取。个人强度，请勿上升至路线。

人苏的老师人很好，我最后还是鸽了他。当时上交缩招，我不敢只攥一个 offer，怕软微也出这种事，人苏就成了保险。鸽他的时候我真的掉了眼泪，我这个人比较感性。

## 高瓴

第四个是人大高瓴人工智能学院，简称高瓴。我是摆烂着去的：人苏的老师我已经找好了，他同时也是高瓴的老师，我去高瓴主要是想跟他当面聊聊。

笔试我是裸考。数据结构与算法几乎全做出来了。数学里有几道全微分的题，我忘了怎么做，概率论拿下了，数学是我唯一不怕的科目。机器学习那门课我没学过，卷子上写的我看不懂，只知道原理和大致的算法，不会推公式，而他考的就是一堆公式，我纯靠猜加一点推理。算法题是一道很难的 LeetCode，我写了前两问，第三问好像很少有人写得出来。英语翻译，手撕。

笔试考得不错，面试我犯蠢了。

第一题是 DAG 上算路径。老师一直觉得要判重，我一直觉得不用，DAG 上每条路径互相独立，为什么要判重？他让我再想想，我想了一分钟，没有结果。

接着问了数学的介值定理，我背出来了。然后考了个求根，我没看到题目里写了函数单调，第一反应是牛顿法。老师问我误差怎么算，我蒙了，现场自己编了一个算法。标准答案是很简单的二分。

高瓴最后我是专硕第十八名，面试应该是挂了，全靠笔试撑着。后来吃到了候补优营。要是面试不犯蠢，名次完全可能更高。或者别裸面，提前准备一下。

## 八月

高瓴之后，我一直玩到八月末。这段时间我陆续报了上交软件学院（别问为什么报软，我自己也不知道）、复旦计算机、南大计算机和南大软件，都入了营，只是通知来得有早有晚。我当时觉得，uestccs rank1 已经无敌了。

八月末，我进了清深（清华大学深圳国际研究生院）的 LLM 方向，走的强 com。

我原本打算拼一把，实在不行就退下来打清深的大数据：进了 LLM 还能进不了大数据？结果清华把我的志愿卡了，我只进了 LLM 这一个方向，大数据和工程硕都被卡死了。

我对能不能过 LLM 不抱信心，决定自己拼一把，不留遗憾。玩命卷了两天，面试也尽力了。唯一的失误是一开始太紧张，喊了一句 good morning，但那是下午。

没拿下。后来我听说，有一个同济的 rank 1 加 A 也没拿下，我就释怀了。清深这条线，基本是清华本校和华五的 rank 1 在抢。入营这一关我无敌，入营之后各凭本事。我有个同学，大数据，rank 1/30+，跟我一样纯 rank，没陶瓷，过了。如果当时是大数据，我觉得我稳。

## 九月

清深面试结束的时候，南大计算机的初赛到了。我本来想拿它的笔试给清深练手，结果它比清深还晚。那就当玩，裸考，过了，超绝的记忆力继续发力。

九月入了姗姗来迟的复旦。老师口头说可以招我，但要先过学院的考核，他自己也没办法。我不确定他有没有捞我。也有人说复旦是弱 com，我不清楚，可能强弱都有。南大软件也入了营，同样来得晚。

上交那边和高瓴冲突，被迫放弃。

## 浙大

之后我同学逼我去套浙大一位很强的老师。他说他觉得我很厉害，不想看到我跟着一个摆烂的羊导沉沦。

我去套了。老师觉得 rank 1 是个人才，说可以给我面试机会，保送我入营，不过面试帮不了，得看我自己的本事。他还提醒我多看看 LLM，因为面试官做这个，不懂我做的搜推。

我报了浙大 AI，被筛掉了，华五里只有浙大没进。今年浙大 AI 似乎卡 A。也可能是我对那位老师爱搭不理，他没有捞我。我不想去强组，硕士想自由一点，不太想继续卷了。我没进营，也没跟他说。

## 回头看

最后去的是北大软微。

学长三月说的那些，后面几乎一条一条应验了。我很感谢他，没有他，就没有这么吃香的我。rank 1 的学弟学妹不用太怕，没有论文，也不会吃瘪。

强 com 的复习，所有的营都用得上。打工只对一个老师有用，所以我整个保研一点工都没打。能靠高 rank 暴力轰过去，我觉得是最省事的打法。当然我是高 rank，肯定替高 rank 说话。我感觉真没几个人认真复习强 com。

陶瓷不一定要有论文，我觉得老师看 match 的程度，比看你发没发一篇更多。面试可以练。我记性好，这条没法复制，但考前复习可以弥补。我自己是外向、冷静、不吃压力又自信的那种，被问到不会的地方还能笑，想走这条路的可以往这边靠。

选老师，我觉得人品最重要。

我不太建议后人照着我学。只为了保研的话，这条路走得通；论文可以后面再发，rank 没了就真没了。最好的打法我觉得是高 rank 加 A，这次我没凑齐，希望毕业的时候能补上。
