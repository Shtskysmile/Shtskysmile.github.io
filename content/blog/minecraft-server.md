# 一起来玩 Minecraft

有同学开了一个 Minecraft Java 版服务器，一个人玩生存总归差点意思，所以在这里宣传一下，欢迎大家来玩。

> [!NOTE] 服务器地址
>
> `nbb.rainplay.cn:15750`（**Java 版**）

## 怎么进服

1. 用官方启动器打开 Minecraft，选择 **Java 版**
2. 主菜单 →「多人游戏」→「添加服务器」
3. 「服务器地址」填 `nbb.rainplay.cn:15750`，名称随便写
4. 保存后双击进服

## 几点说明

- 只支持 **Java 版**。手机版、主机版这些**基岩版**连不上这个地址，别拿基岩版硬试。
- 版本对不上也可能进不去，连不上先检查一下自己的游戏版本。
- 进来先在公屏打声招呼，一起玩得开心点：别拆家、别顺东西、别在别人床边挖坑。
