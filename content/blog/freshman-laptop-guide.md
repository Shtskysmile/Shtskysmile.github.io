# 大一新生买什么电脑

开学前后这个问题会被问很多遍。答案取决于三件事：什么专业、打不打游戏、家里能给多少预算。所以这里不直接给一个答案，摆四套组合，从省事到省钱排下来。

## 1. 直接买游戏本

最省心的选法。

优点是不用想那么多。写代码能跑，打游戏能打，跑个仿真、渲个图、剪个视频也都在能力范围内。一台机器解决所有事，不用在几台设备之间同步文件，也不用纠结哪个软件装哪台。

缺点是沉，背来背去挺锻炼身体，电源适配器还是一大块。教室、图书馆、宿舍来回跑，一天下来肩膀是有感觉的。续航也一般，离了插座性能掉得厉害，在外面基本得找有插座的位置坐。

买的时候认准御三家就行：华硕、联想、惠普。这三家的品控、售后和驱动支持都更稳，出了问题好修，用几年后出手也不至于太掉价。

我自己的主力机是 2023 年的天选 4，R7 7735H 加 4060，内存加到 32G，到现在还是打游戏的首选，基本什么游戏都带得动。后来写代码换到了 MacBook，这台机器跑代码工程照样没问题，编译、构建、起服务都能干，不是只能打游戏。

配置上带独显是底线。~~别在内存上省钱~~（这是我当时的想法，那会儿内存还不贵，现在要掂量一下）。

## 2. 轻薄本 + 游戏本（或台式机）

出行带轻的，宿舍放能算的。

优点是两头都不将就。上课、去图书馆、寒暑假回家带轻薄本，打游戏和跑重活回宿舍用另一台。轻薄本能做到一两公斤，装包里跟本书差不多。

缺点是费钱，两台机器的钱。台式机同样性能比笔记本便宜不少，能追回来一些，但学期末搬回家里很麻烦。快递有摔坏的风险，自己拎回去又太重。

这套方案顺带还有个好处：两台机器天然适合互相备份，一台崩了另一台还能干活。

## 3. 只买轻薄本

最省钱的选法。

优点是钱花得少，也不用背一坨铁。日常写代码、写文档、看视频完全够用，现在的轻薄本 CPU 对付本科阶段的作业没什么问题。

缺点是打游戏基本没戏，另外要性能就只能去租服务器。训练模型、跑实验这类需求在云上租卡很常见，按小时算钱，不用的时候停掉就行。

工科软件是另一个麻烦。MATLAB 这种要授权的软件，装到服务器上用盗版不行，正版授权按人按机器算，学生版和个人版各有各的限制。比较现实的办法是借同学的游戏本，或者去机房用学校的正版授权。

## 4. 计算机专业：二手 MacBook + 游戏本（或台式机）

如果确定是计算机专业，推荐这套。

MacBook 对写代码这个人群体感确实好。底层是 UNIX，终端、ssh、包管理器、各种开发工具都能直接用，配环境踩的坑比 Windows 少很多。加上续航和重量，带去上课很舒服。

买二手就够。老几代的 Air 或者 Pro 价格不贵，写四年代码绰绰有余。~~内存尽量上 16G，8G 现在有点紧~~（内存越来越贵了）。

缺点也直接：不是所有人都能接受 macOS。有人就是要用 Windows，有人需要的工具只有 Windows 版。嵌入式方向的一些烧录和调试工具链、部分 CAD 和仿真软件在 Mac 上要么没有、要么难用，这些方向的人用这套方案反而是添麻烦。

## 最后

不确定选哪个的话，游戏本是最不容易后悔的一个。

剩下三套都有前提。轻薄本加台式机的前提是预算够，只买轻薄本的前提是不打游戏也不跑重活，二手 MacBook 的前提是你能接受 macOS 而且专业方向对得上。先想清楚自己属于哪一类。

还有一条和上面几套都无关：不管怎么选，手边最好有一台 Windows 电脑兜底。学校的考试系统、部分课程指定要装的软件、一些专业工具链，只有 Windows 版，临时赶上了很耽误事。家里旧的先别卖，买轻薄本的时候也可以直接挑 Windows 的。多这么一台，能省掉不少麻烦。
